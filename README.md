## 这是一个桌游合集项目

---

## 🧰 技术栈

- **HTML5** – 页面结构
- **Tailwind CSS** – 快速、可定制的样式
- **JavaScript (ES6)** – 核心游戏逻辑与交互
- **PeerJS** – WebRTC 封装，简化点对点数据通道的建立

---
## 项目结构
```
jungle/
├── index.html          # 主入口页面
├── games/              # 游戏目录
├── js/                 # 公用 js 资源
└── css/                # 少量自定义样式（主要使用 Tailwind）
```

## 游戏目录

```
- **catan** – 卡坦岛 Catan
- **quoridor** – 路墙棋 Quoridor
- **jungle** – 斗兽棋 Jungle
- **abracadawhat** – 出包魔法师 Abraca... What?
- **bombcat** – 炸弹猫 Bomb Cat
- **chinese_chess** – 中国象棋 Chinese Chess
- **coda** – 达芬奇密码
- **gomoku** – 五子棋 Gomoku
- **memory** – 记忆大师
- **monopoly** – 大富翁 Monopoly
- **reversi** – 黑白棋 Reversi
- **rummikub** – 拉密 (Rummikub)
- **smart_block** – 机智方块 Smart Block
- **tictactoe** – 井字棋
```
