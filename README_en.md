## Board Game Collection

---

## 🧰 Tech Stack

- **HTML5** – Page structure
- **Tailwind CSS** – Fast and customizable styling
- **JavaScript (ES6)** – Core game logic and interactions
- **PeerJS** – WebRTC wrapper, simplifying peer-to-peer data channel establishment

---

## Project Structure

```
jungle/
├── index.html          # Main entry page
├── games/              # Game directory
├── js/                 # Shared JavaScript resources
└── css/                # Custom styles (Tailwind handles most)
```
